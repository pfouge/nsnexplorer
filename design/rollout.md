# Rollout by page type, in traffic order

Principles: (1) overview first, zoom and filter, details on demand; (2) grouping by proximity and space;
(3) position, size and one accent carry what matters, colour never alone; (4) data-to-ink; (5) hierarchy by
size, weight and position, not boxes; (6) consistency; (7) progressive disclosure, choices remembered for
the visit.

Shared to every page: one type scale (13/15/20/28, 400/600), hairlines instead of boxes, navy for links and
selection, green and red only for up and down, sticky table headers, right-aligned tabular numbers, long
tables opening on a few rows with "Show all N rows" (rows stay in the HTML), reference text in closed folds,
sections in groups behind pressed buttons with an "All" button, the flag in the header, the institutions
row in the footer, ad positions fixed in source order (empty while ads are off).
